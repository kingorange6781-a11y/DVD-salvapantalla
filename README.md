# 🌹 VibeSaver - New Functions to TV

**VibeSaver** es una aplicación multiplataforma diseñada especialmente para **Android TV**, combinando un salvapantallas clásico y personalizable con herramientas prácticas para el día a día en la televisión.

---

## ✨ Características Principales

* **📺 Salvapantallas DVD Dinámico:** El clásico logotipo de DVD rebotando por la pantalla, optimizado para cualquier resolución con cambio automático de colores y tamaño adaptativo.
* **🌙 Filtro Oscuro (Modo Noche):** Una herramienta integrada en el menú principal para aplicar una capa semitransparente que reduce drásticamente el brillo de la pantalla, ideal para dejar la televisión encendida durante la noche.
* **🎨 Estética Coral Marino:** Una interfaz limpia, moderna y elegante inspirada en tonos coral y azul marino oscuro para cuidar la vista en entornos oscuros.
* **🚀 Ligera y Eficiente:** Desarrollada con código nativo de Android (Java), sin consumir recursos innecesarios en tu dispositivo.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java
* **Plataforma:** Android TV (Compatible con `DreamService` y `AppCompatActivity`)
* **Herramientas de Build:** Gradle 8.5
* **CI/CD:** GitHub Actions (Automatización de compilación y generación de APKs mediante Releases)

---

## 📦 Instalación y Descarga

Puedes descargar la última versión estable directamente desde la sección de **[Releases](../../releases)** de este repositorio.

1. Descarga el archivo `.apk` desde la última Release.
2. Instálalo en tu Android TV (puedes usar aplicaciones como *Send Files to TV* o un explorador de archivos con soporte USB).
3. ¡Disfruta de **VibeSaver**!
